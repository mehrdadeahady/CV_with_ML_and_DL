For extending or modifying ui.ui inside QtDesigner:

After making changes in QtDesigner, run pyuic6 in the terminal to convert the design into Python code for Qt6:
(You can load the .ui file directly, but editing will be more difficult.)

pyuic6 -x -o ./temporaryFile.py ./ui.ui

Explanation:

pyuic6 — command

-x — makes the output executable

-o — specifies the path and name of the output temporary file, here temporaryFile.py  
< The output file name should be different from existing Python files in the project to avoid overwriting >

ui.ui — .ui is the extension for QtDesigner files, helping you modify the UI easily and quickly.

Ui_MainWindow class in temporaryFile.py should be updated as follows:
#**************************************************************************
From the Ui_MainWindow class in the old Ui_MainWindow.py (inside the utilities folder), copy the code located between the symbol lines (these lines have comments beside self: like this → #*******************************).
#**************************************************************************

(There are 3 blocks: 2 blocks in the setupUi function and 1 block in the retranslateUi function.)
Replace the corresponding lines in the Ui_MainWindow class inside temporaryFile.py with the copied blocks.

Now replace the old Ui_MainWindow class inside Ui_MainWindow.py with the updated Ui_MainWindow class from temporaryFile.py.
You can delete the temporaryFile.py file afterward.
